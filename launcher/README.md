# ShadowFoxTV Launcher Pro

Install [version 1.4.9](https://raw.githubusercontent.com/gervaism-afk/shadowfox-tv-releases/main/launcher/ShadowFoxTV-Launcher-Pro-1.4.9.apk) over your existing ShadowFoxTV Launcher Pro. Do not uninstall or clear app data. This first installation adds Settings → Launcher updates → Check for updates for future releases.

Version 1.4.9 also adds Settings → Navigation sounds → On / Off for Android's standard navigation clicks. Apps that play custom sounds may require their own setting. Media volume and HDMI routing are unchanged.

The updater checks HTTPS metadata, download SHA-256, package name, version and signing certificate before opening Android's installation confirmation. The internal package is com.shadowfox.tvlauncher.review to retain existing customization. The APK requires Android 7.0 or later.
