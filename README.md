# ShadowFox TV Platinum Player downloads

This repository contains signed Android APK releases and release notes. App source and signing keys are kept separately.

## First installation of the updater

Download the APK from Releases and install it over your current ShadowFox app. Do not uninstall the existing app first. Android may ask you to allow installations from the app used to open the APK.

The first updater preview is version 1.1.0 (Android version code 2), for Android 7.0 or later. It adds update checks, verified downloads and Android installer support. Guide and appearance improvements are still in progress.

## Later updates

After the updater is installed, the app checks for releases automatically and from Settings → Updates. You choose when to download and install. Android still confirms installation.

## Integrity

Each release includes a SHA-256 checksum. The app verifies its download checksum, package, version and signing certificate before offering installation.
