# Movies & Series 0.3.12 — Categories

Adds a Categories button to Movies and Series, with a scrollable picker for phone touch and TV remote input. Recognized provider labels are grouped under Action, Adventure, Animation, Comedy, Crime, Documentary, Drama, Family, Fantasy, Horror, Mystery, Romance, Sci-Fi, Thriller, Western and Adult when matching provider groups exist. Combined labels can belong to multiple genres. Adult labels are grouped only as Adult and open directly without adding a PIN. Existing kids-profile visibility settings remain in effect.

Original provider categories remain selectable. Genre queries stay scoped to Movies or Series and respect search, saved titles, bounded pagination and counts. Genres without matching provider labels are omitted; titles are not guessed into genres.

Package ca.shadowfoxtv.movieseries, version code 24. Account storage, database schema and signing identity are retained. Install over the existing app.
